# IBM Plex Sans

`IBMPlexSans-Latin.woff2` is the Latin variable subset of IBM Plex Sans,
provided by Google Fonts (v23) for weights 400 through 600. It is served locally;
the console does not request this font from an external service at runtime.
Chinese text uses the configured native CJK sans-serif fallback.
